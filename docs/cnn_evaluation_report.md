# CNN Classifier Evaluation Framework Report

**Module**: Model-Agnostic CNN Evaluation Framework for CWRU Bearing Fault Classification  
**Date**: August 21, 2026

---

## 1. Purpose

The CNN evaluation framework provides a standardized, model-agnostic evaluation suite for rolling-element bearing fault classification. It evaluates predictions and softmax probabilities generated by deep learning models against ground-truth labels from the processed CWRU dataset (`data/processed/cwru/cwru_dataset_v1.npz`).

The framework is decoupled from model architecture and training loops, ensuring that any classifier outputting discrete predictions and probability vectors can be benchmarked consistently.

---

## 2. Input Contracts & Requirements

The evaluation module (`src/evaluation/cnn_evaluation.py`) expects the following outputs from a trained CNN:

1. **`y_true`**: Ground-truth class labels as a 1D integer array of shape `(N,)` with values in `{0, 1, 2, 3}`.
2. **`y_pred`**: Predicted class labels as a 1D integer array of shape `(N,)` with values in `{0, 1, 2, 3}`.
3. **`y_prob` (Optional)**: Softmax class probabilities as a 2D float array of shape `(N, 4)`.
   - Must be finite in $[0, 1]$.
   - Each row must sum to approximately $1.0$.
   - Preserved for downstream uncertainty estimation without premature conversion.
4. **`history` (Optional)**: Dictionary containing training and validation loss/accuracy trajectories across epochs (`train_loss`, `val_loss`, `train_accuracy`, `val_accuracy`).

---

## 3. Evaluation Metrics

The framework computes both overall and per-class performance metrics:

### Overall Metrics
- **Accuracy**: Fraction of correctly classified windows over all classes.
- **Macro Precision / Recall / F1-Score**: Unweighted arithmetic mean across all 4 classes, treating each fault class equally regardless of support.
- **Weighted Precision / Recall / F1-Score**: Class metrics weighted by their respective sample counts (support), reflecting aggregate test performance.

### Per-Class Metrics
For each of the four baseline classes:
- **Precision**: $\frac{\text{TP}}{\text{TP} + \text{FP}}$ (positive predictive value).
- **Recall**: $\frac{\text{TP}}{\text{TP} + \text{FN}}$ (sensitivity / fault detection rate).
- **F1-Score**: Harmonic mean of precision and recall: $\frac{2 \cdot P \cdot R}{P + R}$.
- **Support**: Number of true occurrences of each class in the evaluation set.

## 6. Class Imbalance Considerations

The processed CWRU dataset has the following window distribution across 40 source recordings:

| Class | Health State | Total Windows | Percentage |
| :---: | :--- | :---: | :---: |
| **0** | Normal Baseline | 232 | 10.0% |
| **1** | Inner Race Fault | 696 | 30.0% |
| **2** | Ball Fault | 696 | 30.0% |
| **3** | Outer Race Fault | 696 | 30.0% |
| **Total** | — | **2,320** | **100.0%** |

Because the Normal class has fewer recordings (4 files vs 12 files for each fault type), **accuracy alone is not a sufficient evaluation criterion**. A classifier that performs poorly on Normal signals could still achieve $>85\%$ overall accuracy. Macro F1-score and per-class recall must be used as the primary benchmark criteria.

## 8. Summary of Components NOT Implemented Yet

To maintain strict modularity and prevent premature coupling, the following components remain intentionally un-implemented at this stage:
- **CNN Architecture & Training**: Will be implemented in the subsequent CNN modeling milestone.
- **Novelty Detection**: Isolation Forest / distance-based embedding scoring.
- **Uncertainty Estimation**: Conversion of `y_prob` to normalized uncertainty score $U \in [0, 1]$.
- **VoI Integration**: Direct feeding of real sensor metrics into `VoIEngine`.
- **FSO Communication**: Channel modeling and physical transmission simulation.
